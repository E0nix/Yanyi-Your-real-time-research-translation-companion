# 研译 · 学术双语翻译

研译是一款面向科研阅读的浏览器扩展，帮助读者在网页中对照原文与译文，并通过划词查询理解专业词汇。

## 功能

- 网页双语翻译与划词查询，支持电化学等专业领域的翻译提示（当前版本为先行版，后续更新的版本会新增更多预先设置好的领域提示词，请各位大大耐心等待）。
- 微软快速翻译，以及可自行配置的 OpenAI Chat Completions、Anthropic Messages 兼容接口。
- 支持 Magpie 等本机兼容网关，自选模型和目标语言（力荐用magpie反代workbuddy来做翻译，具有响应速度快、精准且经济的优点）。
- 可拖动悬浮球、屏幕附近内容优先、译文流式显示及本地缓存。

## 安装

1. 下载 Release 中的 `Yanyi-0.7.2.zip` 并解压到固定文件夹。
2. 在 Edge 或 Google 中打开 `管理扩展`，启用开发人员模式。
3. 选择“加载解压缩的扩展”，选择解压好的 `Yanyi-0.7.2`文件夹。
4. 打开扩展设置，选择默认微软翻译，或配置自己的模型服务。

## 使用

点击悬浮球翻译或还原网页，拖动悬浮球可改变位置。按住 `T` 并用鼠标左键选中文字可查询；英文单词和短语的释义、例句由已配置的大模型生成。鼠标悬停在悬浮球上可选择目标语言和打开设置。

## 注意事项

网页内容会发送给所选翻译服务；API 调用是否收费取决于服务商和账户。模型密钥与缓存保存在浏览器扩展本地存储中。各网站排版不同，公式、复杂组件及受浏览器限制的页面可能无法完整翻译。微软快速翻译接口的可用性可能随服务调整发生变化。

当前版本尚不支持 PDF 排版翻译、视频字幕和漫画翻译。请在遵守目标网站及服务商适用规则的前提下使用。
